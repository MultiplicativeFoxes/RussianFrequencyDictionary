# Частотный Словарь Русского / Russian Frequency Dictionary
Базируется на Частотном словаре современного русского языка (на материалах Национального корпуса русского языка). М.: Азбуковник, 2009. О. Н. Ляшевская, С. А. Шаров 

Отсортирован по коэффициенту Жуйана, количеству сегментов корпуса, в которых слово встречается и затем самой частоте слова.
